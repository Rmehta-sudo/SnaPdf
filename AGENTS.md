## Mandatory live project memory

1. Read `PROJECT_CONTEXT.md`, then use `project-memory/INDEX.md` to open only relevant topics.
2. On every substantive prompt, canonicalize new or changed non-reconstructable facts in the
   relevant topic/`FACTS.md`; update `PROJECT_CONTEXT.md` when the shared current picture changes.
3. Run `python3 scripts/project_memory/project_memory.py sync` at the start of project work, at
   least every three substantive prompts, after durable milestones, and before handoff, compaction,
   archive, or completion. Run `validate` before declaring completion.
4. Search cold evidence selectively; never load it wholesale. Recheck live external state at source.
5. Mark conflicts superseded with provenance. Never store secrets or silently erase history.

Follow `project-memory/MAINTENANCE.md` for inclusion and source-priority rules.
